# Grafika

- `logo.png` – główne logo (kwadrat, przezroczyste tło): README, instrukcja PDF, okno aplikacji.
- `banner.png` – wersja pozioma z ciemnym tłem: nagłówki, kanał.
- `mark.png` – znak bez tekstu (bolid + fala): źródło ikony.
- `icon.png` (512×512), `icon.ico` (16–256 px) – ikona okna i pliku `.exe` (etap 6), wygenerowane z `mark.png`.
