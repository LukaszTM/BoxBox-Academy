# Realne kształty torów

`<track_id>.json`: pozycja auta gracza co 10 m okrążenia (z pakietu Motion) plus pozycje apeksów
z pliku toru. Tworzy je reporter (`python -m boxbox.reporter` lub `BoxBoxReporter.exe`) z sesji
z co najmniej jednym pełnym okrążeniem. Obok w raporcie jest SVG z obrysem do obejrzenia.
